# Муха

Персональный плагин проекта полной нейронной ЦНС MaleCNS. Навык
`$work-with-mukha` помогает выбрать решающий опыт, сохранить биологический
контракт, найти существующий исходник и применить профильные GPU/Molab навыки.

Это исследовательские инструкции и три небольших средства проверки.
Плагин не содержит обученную муху и не гарантирует достижение биологии или KSP.
Он не запускает работу автоматически, не меняет конфигурацию GPU и не читает
секреты. Карта проекта составлена 24 сентября 2026; состояние нужно сверять.

## Использование

В новом чате: «Используй `$work-with-mukha` для следующего эксперимента MaleCNS».
В уже работающем чате можно явно прочитать абсолютный путь
`skills/work-with-mukha/SKILL.md` установленного плагина без перезапуска задачи.
Для автоматического обнаружения новых навыков используйте новый чат.

Навык маршрутизирует шесть руководств: карта проекта, биология, нативное
исполнение, артефакты/Molab, тело/кабина/KSP и выбор эксперимента.
Сопутствующие плагины применяются по необходимости и не являются обязательными
зависимостями. Наличие установленного навыка не доказывает его применение.

## Вспомогательные команды

Python 3.10+, только стандартная библиотека. Запускайте из папки плагина:

```text
python scripts/project_snapshot.py --workspace <project-root>
python scripts/verify_manifest.py --root <artifact-root> --manifest <manifest.json>
python scripts/inspect_skill_usage.py --session <explicit-session.jsonl>
python -B -m unittest discover -s tests -v
```

Все три помощника только читают и выводят JSON в stdout. Обзор ограничен
списком небольших файлов и не устанавливает состояние удалённых процессов.
Проверка манифеста читает все перечисленные файлы; используйте её на завершённом
неизменяемом наборе. Она не доказывает происхождение данных и не ищет пропущенные
файлы. Формат (не универсальный парсер существующих манифестов проекта):

```json
{"files":{"source.cpp":{"bytes":123,"sha256":"<64 hexadecimal characters>"}}}
```

Анализ журнала распознаёт некоторые явные команды чтения SKILL.md. Он не
открывает другие журналы, не выводит аргументы команд и не доказывает, что
инструкции прочитаны успешно или применены. Пути, вычисленные в переменных,
и другие способы чтения могут быть пропущены. Применение проверяют по решению
агента и соответствующему артефакту.
