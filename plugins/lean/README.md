# Lean

Персональный плагин для формализации в Lean 4 и Mathlib. Навык `work-with-lean` помогает сохранить точную математическую задачу, диагностировать ошибки установленной версии библиотеки и проверить свидетельства сборки.

Примеры запросов:

- «Используй плагин lean: формализуй это утверждение без изменения гипотез».
- «Разбери ошибку Lean по точной цели и исходникам установленной Mathlib».
- «Проверь полноту покрытия источников, сборку и транзитивные аксиомы».

Внутри: [навык](skills/work-with-lean/SKILL.md), [разбор агента](AUDIT_RU.md), [инструмент проверки](skills/work-with-lean/scripts/lean_evidence.py), [команды и ограничения](skills/work-with-lean/references/runtime-and-evidence.md).

Требования инструмента: Python 3.11+, без внешних пакетов. Для реальных Lean-проверок используется уже существующий Lean/Lake или разрешённый проектом Docker-запуск. Плагин не содержит дистрибутив Lean и не скачивает зависимости автоматически.

Проверка вспомогательного инструмента:

```text
python -B -m unittest discover -s skills/work-with-lean/scripts -p test_*.py -v
```

После установки плагина начните новую задачу для загрузки навыка. Существующая основная задача не получает новые инструкции задним числом.
