# Optional integrations, with standalone fallbacks

Use another installed skill only when it serves the user's task and is actually available. Beautiful Science needs no external plugin, API, model service, or network connection.

## Scientific writing

For a paper or report, pass the exact claim, evidence status, scope, alternatives, and unresolved obligations to the writing step. Figures should expose a dependency, regime, counterexample, or discriminator. Preserve uncertainty when polishing the story. Do not rewrite an exploratory sequence as an inevitable discovery or omit failures that matter to the inference.

If a scientific-writing skill is available, it can help structure the exposition; otherwise use these principles directly. Writing quality does not upgrade scientific evidence.

## Logic / logika

For argument repair, identify premises, quantifiers, implications, necessary versus sufficient conditions, and the exact inference at issue. Distinguish inconsistency, invalid inference, false conclusion, and missing premise. Check whether the repaired premise is independently justified or merely equivalent to the desired result.

If `logika` or a proof assistant workflow is available, use it for the relevant formal obligation. Otherwise produce the dependency argument and a minimal counterexample directly. A successful formal check applies to its formal statement and trust base, not automatically to the intended scientific interpretation.

## TRIZ

For an engineering contradiction, preserve both requirements explicitly: for example, reduce query latency while respecting total preparation cost and memory. Generate a changed representation, decomposition, selective computation, reuse pattern, or altered physical mechanism. State which constraint the candidate changes and which it retains.

If a TRIZ skill is available, it can broaden candidate generation. Otherwise use the contradiction and alternatives directly. A inventive pattern is a source of hypotheses; it returns to evidence, correctness, full-cost, and applicability checks before being adopted.

## Hand-off contract

Pass only what the next task needs: objective, exact claim, inspected artifacts, evidence limits, the requested decision or obligation, and completion condition. Do not pass a desired verdict as fact. Integrations neither grant new permissions nor require the user to install another plugin.
