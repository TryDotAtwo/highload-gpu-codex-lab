# Scientific Writing 0.2.0 — кандидат

Один основной пакет: `scientific-writing`. Он заменяет узкую точку входа `clear-russian-writing`, но старый пакет и ZIP 0.1.0 сохранены без изменений. Автоматический alias `write-clear-russian` не добавлен: два одинаково срабатывающих редактора создавали бы неоднозначность.

Четыре отдельные роли:
- `write-clear-explanations`: объяснения в статьях, книгах, отчётах и учебных текстах на разных языках; общие принципы отдельно от языковых норм
- `work-with-prism`: обязательный реальный проект и агент Prism при подготовке/существенной редактуре рукописей, связь review с версией, честная остановка при блокере
- `write-visual-research-papers`: сохранены доказательные границы, claims ledger, time/memory scaling, рисунки и постраничный QA
- `technical-style-editor`: сохранены EN/RU правила, диагностический скрипт и границы утверждений

Это структурно проверенный кандидат, а не доказательство качества во всех языках. Новые E1/P1/P2 behavioral tests: NOT_RUN — fresh-agent запуск отклонён лимитом потоков. Старые русские тесты сохранены отдельно и относятся только к прежним русским версиям. Новая иллюстрация English — авторский пример, не тестовый результат. Исторические Prism receipts подтверждают выполненные операции, а не эффективность новой инструкции.

## Перед установкой

Проверить CHANGELOG.md, EVALUATION.md и файлы validation. Установку выполняет владелец отдельно после review; узкая ручная проверка координатором записана в EVALUATION.md. При миграции оставить единственный активный источник каждой роли: отключить старый clear-russian-writing и самостоятельные дубли двух включённых skills только в рамках разрешённой пользователем миграции. Сохранить архивы для отката. Сам пакет ничего не удаляет и не меняет настройки.

Плагин содержит инструкции, не подключение к Prism, не учётные данные и не установку плагинов внутри Prism. Для реальной работы требуется авторизованный доступ. Короткие обычные чат-ответы не обязаны проходить Prism.
