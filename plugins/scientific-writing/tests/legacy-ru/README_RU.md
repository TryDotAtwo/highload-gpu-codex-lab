# Как воспроизвести чтение тестов

Основные пары:
- T1–T5: baseline_prompts.md → baseline.md / with_skill.md
- C1–C2: COMPOSITION_PROMPTS_FROZEN.md → composition_baseline.md / composition_with_skill_v1.md
- U1–U2: TARGETED_PROMPTS_FROZEN.md → targeted_baseline.md / targeted_with_skill_v2.md
- Повтор T4/T5/C1: regression_with_skill_v2.md, те же прежние задания

Все файлы ответов скопированы побайтно из результатов запусков. Их оформление не выправлялось. В baseline U1/U2 заголовки отсутствуют: текст до абзаца о самолётиках относится к U1, последний отдельный абзац о самолётиках — U2.

Для нового сравнения давайте baseline только задание, а treatment — то же задание плюс выбранные инструкции. Не показывайте исполнителю прежние ответы и разборы. Используйте новые контексты и сохраняйте параметры модели, время, сырой ответ и точную версию инструкций. Оценивайте в первую очередь содержание и связное чтение, а не наличие отдельных слов.

instruction_snapshots/v1 и v2 сохраняют файлы инструкций на момент соответствующих прогонов. Старые treatment*_snapshot.sha256 содержат пути исследовательской рабочей папки: для проверки внутри архива замените префикс `plugins/clear-russian-writing/skills/` на `tests/instruction_snapshots/v1/skills/` или `tests/instruction_snapshots/v2/skills/`. В финальной версии изменён геометрический пример и дополнена библиография; поэтому эти исторические реестры не являются реестрами окончательной поставки. Для всей поставки используйте PACKAGE_MANIFEST.json в корне.
