# CNOT Research

Локальный плагин опыта собственной исследовательской ветки TheQuantumProject.
Снимок знаний: 24 сентября 2026. Плагин не запускает обучение автоматически.

Начало: `skills/shorten-cnot-programs/SKILL.md`. Для уже открытого чата передать
агенту абсолютный путь к этому файлу: установка плагина не гарантирует обновление
набора навыков внутри существующего контекста.

Содержимое: механизмы базисного компилятора; корректное обучение поля полной
матрицы; архитектура и стоимость трансформера; неудачные и удачные опыты;
случайные блуждания и точные одностолбцовые проекции диффузии; команды;
проверка полных программ; последовательный план реализации.

`assets/evidence_manifest.json` фиксирует SHA-256 выбранных собственных исходников,
целей, конфигураций и результатов. `assets/snapshot/` содержит копии небольших
сводок и программ, чтобы выводы не исчезли после следующего обучения. Веса,
полные replay и архивы не копируются. Манифест не утверждает полного покрытия
истории чата или формализации всех теорем Frontier.

Из корня проекта:

```powershell
python plugin-build/cnot-research/scripts/check_evidence.py --project .
```

Команда только читает файлы, независимо перемножает доступные полные программы
и сообщает об изменении источников относительно снимка. Она не импортирует
код синтезатора, не загружает pickle/checkpoint и не использует GPU.

Данные и реализации Келипая не входят в плагин. Исторические EA-результаты
с неоднозначным происхождением исключены из обучающих рекомендаций.
Старые отчёты могут отставать от новых реализаций: приоритет имеют датированный
журнал этого плагина и свежие проверенные артефакты.
