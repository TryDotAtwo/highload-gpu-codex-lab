# Sources and Scope

Use these sources when checking terminology or explaining the basis of the workflow.

## TRIZ References

- [MATRIZ Knowledge Base](https://wiki.matriz.org/) provides current terminology and links for TRIZ tools.
- [MATRIZ: Contradictions](https://wiki.matriz.org/docs/triz/problem-solving-tools-5890/contradictions/) distinguishes engineering and physical contradictions and describes their relationship.
- [MATRIZ: Ideal Final Result](https://wiki.matriz.org/docs/triz/problem-solving-tools-5890/ariz-5892/ideal-final-result-5922/) defines the ideal final result as a model with minimal system changes and no deterioration.
- [AI TRIZ Body of Knowledge](https://www.aitriz.org/triz/triz-body-of-knowledge) lists ideality, contradictions, ARIZ, Substance-Field Analysis, principles, separation, and system-analysis methods as separate parts of TRIZ.
- [AutoTRIZ](https://arxiv.org/abs/2403.13002) explores LLM-assisted contradiction detection and solution generation.
- [TRIZ Agents](https://arxiv.org/abs/2506.18783v1) explores a staged multi-agent workflow and documents its prompt sensitivity, token cost, and lack of a feedback loop.

## Scope Statement

This package is a software-oriented problem-solving workflow inspired by selected TRIZ concepts. It is not a complete implementation of classical or modern TRIZ, ARIZ-85C, the 76 standard solutions, Substance-Field Analysis, or any certification curriculum.

The software mappings and principle prompts are original heuristic adaptations. They do not form an official contradiction matrix. Treat them as generation aids and validate every proposed mechanism against the target system.
